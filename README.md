# Roles of Heat Shock Factor HsfB1 in Tomato Heat Stress Response

This repository contains an RNA-seq analysis investigating the role of **Heat Shock Factor HsfB1** in the tomato heat-stress response using **HsfB1 knockdown (KD)** and **overexpression (OE)** models.

The project was implemented in **RStudio**, using **DESeq2** for differential expression analysis and **dplyr** and **ggplot2** for data wrangling and visualization.

The complete rendered Quarto report is available through GitHub Pages:

👉 **[View the interactive analysis report](https://ng-diep.github.io/HsfB1-Tomato-Heat-Stress-Response/)**


## Experimental Design

The experiment compares HsfB1 KD and OE samples under **control (Group A)** and **heat-shock (Group B)** conditions, with three biological replicates per condition.

![Experimental design](experimentaldesign.png)

- **Group A:** 25°C control
- **Group B:** 40°C heat shock for 1 hour
